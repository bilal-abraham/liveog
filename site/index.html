What your links show when they are pasted into a chat or a post. Covers drawn by a browser you already run, addresses that change when the picture does, and nothing a private link should not show.

    01 · No server cost

    Drawn by a browser you already run.

    Your Chrome at build time, or your user's page at run time. The server only checks the PNG and keeps it.

    02 · Always current

    Versioned cover addresses.

    /c/<id>/<v>.png. An old version redirects to the newest; a stopped link's picture is gone.

    03 · Private by kind

    Invites and shares keep their secrets.

    No code or token in the preview, and out of search, Referers and caches.

    By hand

    Three lines in your server.

    Node 22+, Deno, Bun, Cloudflare Workers, Vercel.

    npm i liveog
npx liveog cover "Your site" public/og/home.png
    // where your server sends a page
import { links, originOf } from 'liveog';
const site = links('yoursite', kinds, home);
res.end(site.page(html, path, originOf(host)));
